# Qt 6 Widgets for the IFS editor UI

The IFS editor is a separate executable in this repo built on Qt 6 Widgets with Qt Advanced Docking System, while the renderer keeps Dear ImGui. The editor is meant for public use and needs large trees, property grids, text entry, high DPI and saved dock layouts, which Qt provides and ImGui would need months of custom work for; the timeline and curve editor are custom in either toolkit. WinUI 3 was rejected for its MSBuild-bound XAML compiler and missing editor controls, a C# front end for splitting the document model across two languages, and a custom UI for building a toolkit before the editor. Qt's LGPL terms require dynamic linking, so the editor has its own CMake preset with a dynamic vcpkg triplet and the shared code is built again for it.
